## Bot-v3: The third iteration of our Discord bot.
### Usage
The bot uses slash commands and ComponentsV2. It's fairly simple to understand.

#### Dependencies
* MongoDB
* Roblox ranking cookie and API key
* Rozod
* ...or just run `pnpm i` to install all dependencies.

### Installation
Git clone our repository, then run `pnpm i` / `npm i` to install all dependencies. Then, run `pnpm run dev` to start the bot in a development environment. You can run `pnpm run build` to build the bot for a stable release of the bot.
